DualHoch3: ILIAS Skin and Style
===============================

This is a customized version of the ILIAS Delos system skin and style
for the DualHoch3 project and its ILIAS systems running on [dualhoch3.de](https://dualhoch3.de).

This repo follows the recommended best-practices by the ILIAS developers
to fork the Delos style from https://github.com/ILIAS-eLearning/delos
and modify the SASS files.
